動線可視化ツール 利用手順

1. ZIP ファイルを展開する
- ZIP を右クリックして「すべて展開」を実行します。
- 展開後に次の 2 つがあることを確認します。
  - `VisualizeMovement`（または `VisualizeMovement.app`）
  - `VisualizeMovementData`

2. 起動する
- Windows: `VisualizeMovement` フォルダ内の `VisualizeMovement.exe` をダブルクリックします。
- macOS: `VisualizeMovement.app` をダブルクリックします。
- 既定ブラウザで画面が自動表示されます。

3. データを更新する
- 受け取った新しいデータで `VisualizeMovementData/data` フォルダを上書きします。
- アプリ本体（`VisualizeMovement` / `VisualizeMovement.app`）は更新不要です。

4. 起動しない場合
- ZIP 展開前の場所からではなく、展開後フォルダから起動してください。
- `VisualizeMovementData` がアプリと同じ階層にあるか確認してください。
- Windows の警告画面が出る場合は「詳細情報」→「実行」を選択してください。
- macOS でブロックされた場合は「システム設定 > プライバシーとセキュリティ」から実行を許可してください。
